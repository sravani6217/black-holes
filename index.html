Scientific Scope and Limitations

This project uses the Schwarzschild solution as a theoretical baseline. M87* and Sagittarius A* may rotate, so Kerr geometry is needed for a more complete description. Some visualisations are schematic, while the displayed physical quantities use idealised mathematical formulas.
